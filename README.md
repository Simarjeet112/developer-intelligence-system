# Developer Intelligence System

An AI-powered code analyzer that learns your coding patterns and helps you avoid repeated mistakes.

## Demo
Watch it in action: https://youtu.be/MwewkFQiPbM?si=Uze8AjinqncUKIpL

## What It Does
Analyzes your code in real-time, detects common bugs (loop errors, recursion issues, logic flaws), gives you a score, and tracks which mistakes you make most often.

## Built With
React • Node.js • MongoDB • Monaco Editor • Recharts

## Quick Start
```bash
# Backend
cd server && npm install && npm start

# Frontend (new terminal)
cd client && npm install && npm run dev
```

Open http://localhost:5173

## How It Works
1. Write code in the editor
2. Click "Analyze"
3. See your mistakes + score
4. Check dashboard for error patterns
