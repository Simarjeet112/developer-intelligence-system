# 🚀 Developer Intelligence System

A full-stack Developer Intelligence Engine that analyzes code, detects recurring logical mistakes, and builds a persistent Error DNA profile for each developer.

🎥 Demo Video:  
https://youtu.be/MwewkFQiPbM?si=Uze8AjinqncUKIpL

---

## 🧠 What It Does

- Detects logical mistakes (e.g., loop boundary issues)
- Assigns a logic score
- Tracks recurring errors over time
- Builds a behavioral Error DNA profile
- Visualizes weakness distribution using a radar chart

---

## 🏗 Tech Stack

**Frontend**
- React (Vite)
- Monaco Editor
- Recharts

**Backend**
- Node.js
- Express
- MongoDB (Mongoose)
